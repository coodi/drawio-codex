# draw.io for Codex

Локальный плагин Codex на основе официальных исходников [jgraph/drawio](https://github.com/jgraph/drawio). Включает оригинальный редактор draw.io **31.7.0**, MCP-сервер и skill для работы с диаграммами из чата. Python-сервер использует только стандартную библиотеку; ключ API и npm-зависимости не нужны.

## Возможности

- Создание `.drawio` из списка узлов и связей или полного XML.
- Чтение всех страниц, включая сжатые страницы draw.io.
- Изменение XML с проверкой версии файла, чтобы обнаруживать конфликты.
- Оригинальный редактор draw.io в браузерной панели Codex.
- Автосохранение ручных правок в тот же файл; обновление редактора после правок Codex.
- Экспорт SVG и PNG средствами draw.io через открытый редактор.

## Установка

Требуются Python **3.10+** и Codex с поддержкой локальных плагинов Agent Plugins. После установки плагин доступен как `drawio@drawio-local`.

Для установки на другом компьютере распакуйте архив, перейдите в его папку `drawio-codex` и выполните:

```bash
codex plugin marketplace add .
codex plugin add drawio@drawio-local
```

Если команда `codex` отсутствует в PATH, используйте путь к вашему Codex CLI. В Linux-окружении, где создавался плагин, это `/usr/lib/chatgpt/resources/codex`.

Откройте новый чат Codex после установки. Если плагин не появился, перезапустите приложение. В чате можно написать:

> Используй drawio: создай схему «клиент → API → база данных» и открой редактор рядом с чатом.

Для обновления установленной копии после изменения исходников повторите `codex plugin add drawio@drawio-local`, затем откройте новый чат. Установка копирует содержимое плагина в кеш Codex.

## MCP-инструменты

| Инструмент | Назначение |
| --- | --- |
| `create_diagram` | `path`, `nodes`, `edges`; либо `path`, `xml`. `overwrite` по умолчанию выключен. |
| `read_diagram` | Возвращает XML, revision и ячейки каждой страницы. |
| `write_diagram` | Принимает `path`, `xml`, `revision` предыдущего чтения. |
| `open_editor` | Возвращает URL локального редактора; откройте его через `open_in_codex`. |
| `export_diagram` | `path`, новый `output`, `format`: `svg` или `png`. |

Все пути абсолютные. Сервер привязан к `127.0.0.1`, использует случайный порт и токен для доступа к документу. API работает только с файлами, для которых вызван `open_editor`. MCP-инструменты могут читать и изменять `.drawio`-файлы по указанным абсолютным путям с правами пользователя.

При конфликте редактор останавливает сохранение и предлагает скачать несохранённые правки. Кнопка загрузки файла с диска позволяет продолжить работу после разрешения конфликта.

## Исходники draw.io и сборка

Upstream-репозиторий: `https://github.com/jgraph/drawio.git`.
Закреплённый commit: `24b76c2cbd55d88e354042e8d329a2e4708972bc`.
В плагин включён неизменённый `src/main/webapp`; интеграция находится отдельно в `web/` и `scripts/`.

Архив поставляется с редактором. В Git-репозитории крупные upstream-ресурсы исключены из отслеживания и восстанавливаются по закреплённой версии:

```bash
python3 plugins/drawio/scripts/fetch-source.py
python3 scripts/package.py
```

Первой команде нужны Git и доступ к GitHub. Если `webapp` уже есть, загрузчик оставляет его на месте и завершает работу с сообщением. Сборщик создаёт `dist/drawio-codex-0.1.0.zip`: готовый локальный marketplace и плагин с ресурсами редактора.

## Проверка

```bash
python3 -m unittest discover -s tests -v
node --check plugins/drawio/web/bridge.js
python3 tests/codex_smoke.py
python3 tests/browser_smoke.py
```

Первые тесты проверяют XML, сжатые страницы, конфликт версий, HTTP-доступ и MCP-протокол. `codex_smoke.py` проверяет обнаружение пяти инструментов установленного плагина самим Codex без обращения к модели. Для него можно задать `DRAWIO_CODEX_BIN`.

`browser_smoke.py` выводит URL: откройте его в Codex, дождитесь диаграммы и нажмите Enter в терминале. Проверка экспортирует SVG/PNG в `dist` и держит MCP-сервер открытым до второго Enter. Для повторного запуска переместите предыдущие `dist/browser-smoke.svg` и `.png`.

В этой среде также проверены ручное сохранение из редактора и отображение внешней правки файла.

## Работа без MCP

```bash
python3 plugins/drawio/scripts/drawio.py call create_diagram '{"path":"/absolute/path/diagram.drawio","nodes":[{"id":"a","label":"Клиент"},{"id":"b","label":"API"}],"edges":[{"source":"a","target":"b"}]}'
python3 plugins/drawio/scripts/drawio.py serve /absolute/path/diagram.drawio
```

`serve` выводит URL и работает до Ctrl+C. Редактор существует, пока работает его MCP-сервер или терминал с `serve`.

## Ограничения

Экспорт SVG/PNG требует открытой вкладки редактора и завершается по тайм-ауту через 30 секунд. Headless-экспорт и PDF не реализованы. Полный XML поддерживает сложные фигуры и страницы; упрощённый генератор nodes/edges создаёт одну страницу. Интеграция использует локальные файлы; облачные хранилища draw.io не подключены. Некоторые специальные функции upstream, например внешние изображения или удалённый экспорт, могут требовать сеть. Размер входного XML ограничен 16 MiB.
